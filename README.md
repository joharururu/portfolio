# 조하루 BX Portfolio

빌드·패키지 설치 없이 실행하는 HTML/CSS/JavaScript 웹사이트입니다.

실행: 이 폴더에서 `python3 -m http.server 4173 --bind 127.0.0.1` 후 http://127.0.0.1:4173 을 엽니다. `index.html`을 직접 열어도 동작합니다.

## 콘텐츠 교체

- `content.js`: 프로젝트명, 역할·기간, 소개, 섹션별 본문과 이미지. `src`에 로컬 이미지 경로, `alt`에 이미지 설명을 입력합니다. 빈 `src`는 명확한 플레이스홀더로 표시됩니다.
- `PORTFOLIO.gallery`: 홈의 60개 이미지. Figma의 순서와 너비·높이를 유지합니다. 각 이미지의 `src`, `alt`만 교체하면 됩니다.
- 상세: 각 프로젝트의 `hero`와 `sections[].images[]`. `body`를 채우면 입력 안내 `prompt` 대신 본문이 표시됩니다. 리서치의 `source`, 검증 상태 `status`도 실제 근거에 맞춰 수정합니다.
- 프로젝트 3–5의 이름, 소개와 연락처는 원본에 실제 내용이 없어 입력 대기로 남겼습니다.
- 폰트: Figma의 Noto Sans KR, Google Fonts에서 로드. 인터넷이 없으면 시스템 sans-serif로 대체됩니다.
- `styles.css`: 공통 블록과 프로젝트별 편집 변형. `app.js`: 라우팅, 확대, Grid, 키보드, 스와이프, 스크롤 복원.
